# Custos 360° Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** a aba Custos ganha o layout "Custo 360°" (KPIs, iceberg, termômetro, para onde vai, DNA, classe ABC, concentração, travado) sobre os dados do site.

**Architecture:** contas puras em `web/lib/wcm/custo360.ts` (testadas), um componente de servidor por cartão em
`web/app/(app)/custos/_ui/`, montagem em `custos/page.tsx`; dois parâmetros novos (custo do par, pares/hora) em
Metas e parâmetros, gravados em `_parametros` do cadastro `metas_wcm.json` como a jornada.

**Tech Stack:** Next.js 16 (App Router, server components), React 19, Tailwind 4, vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-20-custos-360-design.md`

## Global Constraints

- pt-BR em todo texto de tela; cores só pelos tokens do site (`--marca-*`, `--serie-1..4`, `--st-*`, `--seq-1..7`), sem hex novo.
- Nenhum valor da empresa no código (o custo do par fica só no cadastro); testes só com dados fictícios.
- Tudo segue o recorte da barra de filtros (`contexto(params)`: período `c.f.ini..c.f.fim`, área, setor, centro, tipo).
- Bloco ou linha sem dado some (nunca mostra zero falso); sem IW38 continua o `SemDados` atual.
- Mobile: página sem rolagem horizontal em 390 px.
- Antes de publicar: `cd web && npx tsc --noEmit && npx vitest run && npx eslint . && npx next build && npx playwright test`.

## Review Focus

- Período sem nenhuma ordem com custo → KPIs "—", termômetro todo "–", concentração e DNA escondidos, sem divisão por zero (teste em Task 1).
- Parâmetros de parada vazios ou zero → iceberg mostra horas paradas e o aviso "Cadastre custo do par e pares/hora em Metas e parâmetros" (teste em Task 1).
- Custo negativo (estorno) numa ordem → entra na soma, mas não vira o "dia mais caro"; dia negativo pinta como zero (teste em Task 1).
- `?cmes=` inválido ou fora do período → cai no último mês do período (teste em Task 1, `mesDoTermometro`).
- Equipamento sem criticidade ABC ou sem cadastro na IH08 → vai para "Sem classe" e não some do total (teste em Task 1).
