# Pasta `dados/`

Usada só quando as pastas do OneDrive configuradas não existem neste computador
(por exemplo, para testar o app fora da rede da empresa). Coloque aqui os exports
do SAP (IW38, MB52, requisições) que o app encontra sozinho.

Tudo nesta pasta, exceto este arquivo, é ignorado pelo Git — dados da empresa
não vão para o repositório.
